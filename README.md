# AI Big Sister – Project Management Tools Assignment

## Overview

This project demonstrates the application of three essential project management tools—Work Breakdown Structure (WBS), Gantt Chart, and Kanban Board—using a hypothetical product called **AI Big Sister**.

AI Big Sister is an AI-powered relationship guidance app designed to help women better understand emotional patterns, improve communication, and receive personalized support.

---

## Project Contents

This repository includes:

* Work Breakdown Structure (WBS) – hierarchical breakdown of project phases, deliverables, and tasks
* Gantt Chart – project schedule with timelines, dependencies, and milestones
* Kanban Board – visual workflow for tracking task progress

---

## Project Description

The project focuses on planning the **MVP (Minimum Viable Product) launch** of the AI Big Sister application.

The workflow includes:

* Project planning and scope definition
* Market research and user analysis
* Product design and feature planning
* AI system and prototype development
* Testing and iteration
* Marketing preparation and final launch
